# Тестирование Linux-оверлея

Оверлей ни разу не запускался на живом Linux — проверено только юнит-тестами
(включая мок-композитор Wayland) и компиляцией против настоящих заголовков.
Ниже — что собрать, как запустить и на что смотреть.

## Сборка

Нужны: Go ≥ 1.25, gcc, `pkg-config`, `libx11-dev`, `libxext-dev`,
GTK 3 и WebKitGTK 4.1 или 4.0 development packages (на Fedora:
`libX11-devel`, `libXext-devel`, `gtk3-devel`, `webkit2gtk4.1-devel`
или `webkit2gtk4.0-devel`). Wayland-бэкенд — чистый Go, но Petdex browser
собирается через GTK/WebKitGTK.

```sh
sh linux/build.sh
./build/linux/pi-pet-overlay
```

Бинарь сам поднимает демона (сокет `$XDG_RUNTIME_DIR/pi-pet.sock`) и сам
выбирает бэкенд: есть `WAYLAND_DISPLAY` и композитор отдаёт layer-shell →
нативный Wayland; иначе X11/XWayland. Принудительно:

```sh
./build/linux/pi-pet-overlay -backend wayland   # Sway, Hyprland, KDE Plasma, river…
./build/linux/pi-pet-overlay -backend x11       # GNOME (Mutter без layer-shell), Xorg
```

Какой бэкенд выбран — печатается при старте. Полезные флаги: `-scale 2`
(если автоопределение HiDPI промахнулось), `-pets-dir <dir>` (свои петы),
`-open-petdex` (открыть браузер при старте), `-petdex-only` (только браузер
для smoke-тестов).

## Что проверить

Пет должен появиться в правом нижнем углу (боба по умолчанию).

- [ ] **Прозрачность**: вокруг пета нет белого/чёрного прямоугольника.
- [ ] **Click-through**: клики МИМО пета (но в пределах его невидимого
      окна 240×300) проходят в окна под ним.
- [ ] **Поверх окон**: пет остаётся видимым над обычными окнами.
- [ ] **Драг**: пет таскается мышью, анимация бега меняет направление,
      не дёргается, после отпускания иногда говорит реплику.
- [ ] **Клик**: пет машет; иногда реплика (кулдауны — не чаще раза в 15с).
- [ ] **Кириллица в пузырях** читаема (реплики на русском).
- [ ] **HiDPI**: на масштабированном мониторе пет не мыльный и не крошечный.
- [ ] **Pi-интеграция**: `./build/linux/pi-pet-overlay -install-pi-extension`,
      затем запустить `pi` в любом репо — пет бежит во время работы агента,
      просит подтверждение на рискованные команды, машет по завершении.
- [ ] **Petdex**: right-click по телу пета открывает браузер; `Use` выбирает
      установленного пета, `Install to Pi`/`Uninstall Pi` меняют статус Pi
      extension. Для прямой проверки: `./build/linux/pi-pet-overlay -petdex-only`.
- [ ] **Самообновление**: при новых коммитах в чекауте появляется плашка
      «Update available — click»; клик пересобирает и перезапускает.

## Известные ограничения (не баги)

- GNOME Wayland: нативного always-on-top нет (Mutter не реализует
  layer-shell) — работает через XWayland, пет может оказаться под окнами.
- Мультимонитор на X11: стартовая позиция считается от общего экрана,
  пет может появиться не на том мониторе — перетащите.
- Курсор над петом на Wayland пока не задаётся явно (может остаться от
  предыдущего окна).

## Если что-то сломалось

Запустите из терминала и пришлите: вывод stdout/stderr, название
композитора/DE и его версию, `echo $WAYLAND_DISPLAY $XDG_SESSION_TYPE`,
и скриншот. Для Wayland-проблем приложите вывод с `-backend x11` — важно
понять, специфично ли для бэкенда.
